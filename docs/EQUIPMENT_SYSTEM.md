## 5. Crafting (Bastion Workshop)

Combine 2-3 materials -> equip / consumable.
Recipes unlock via library, sidequest, discovery.
Contoh: Iron Sword + Fire Crystal = Flametongue,
Chain + Dragon Scale = Dragon Mail, Potion + Ether = Elixir,
Phoenix Down + Aether Drop = Phoenix Elixir full revive+MP.
Material tiers: Basic common, Refined elite/shop uncommon,
Rare boss/hidden rare, Legendary superboss/true legendary.

## 6. Loot

Enemy mati roll drop = base * (1+luck).
Common 50% 1 item, Elite 100% 1-2, Boss 100% 2-3 + guaranteed rare+.
Luck: Thief +10%, accessories +5-15%.
