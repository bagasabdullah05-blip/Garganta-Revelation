# Garganta Revelation

Dark Fantasy Tactical RPG — Turn-Based Strategy dengan depth ala Final Fantasy Tactics dan Fire Emblem.

## Overview

| Aspek | Detail |
|---|---|
| **Genre** | Turn-Based Tactical RPG |
| **Art Style** | 2D Pixel Art (HD-2D inspired) |
| **Platform** | PC (Steam) + Mobile (Android/iOS) |
| **Engine** | Unity 2D |
| **Tone** | Dark Fantasy, morally grey, political intrigue |
| **Estimasi Main** | 40-60 jam (story), 80+ jam (100%) |

## Core Features

- **Hybrid Grid System** — Isometric dengan zoom control, depth FE + visual FFT
- **CTB (Charge Turn Battle)** — Speed-based turn order
- **Deep Job System** — 16 kelas dengan 3 tier progression
- **Weapon Triangle** — Strategi combat yang mendalam
- **Aether Corruption System** — Risk/reward mechanic yang unik
- **Faction Reputation** — Pilihan menentukan ending (5 endings)
- **Permadeath** — Setiap karakter mati = cerita hilang
- **Recruitment Variety** — 5 cara rekrut karakter

## Quick Start (Development)

### Requirements
- Unity 2022.3 LTS atau newer
- Git
- Visual Studio / VS Code / Rider

### Setup
1. Clone repository ini
2. Buka Unity Hub → Add project from disk → pilih folder ini
3. Tunggu Unity import selesai
4. Buka scene `TestBattle`
5. Press Play
